## Daily Tasks (auto-run, no human input required)

1. **Churn signal monitoring** — Using `churn-prevention`, review: failed payment queue, cancellation requests submitted in last 24 hours, and disengaged user cohort alerts (users with 0 logins in 14+ days). Trigger appropriate save offers or dunning steps for each segment. Log actions in `.agents/outputs/growth-retention/daily-log.md`.

2. **Dunning campaign check** — Review active failed payment recovery sequences. Log: emails sent, payment recovery rate, sequences completed. Flag any subscriber past final dunning step (escalate to manual review if >£X threshold — fill in threshold from `product-marketing-context.md`). Append to `.agents/outputs/growth-retention/dunning-tracker.md`.

3. **Referral programme health** — Check referral link activity: clicks, sign-ups attributed, rewards triggered. Flag any reward fulfilment failures or referral link errors. Append to `.agents/outputs/growth-retention/referral-tracker.md`.

4. **Free tool pipeline check** — Review leads generated by active free tools in the last 24 hours. Log conversion rate from tool user to email capture to trial. Append to `.agents/outputs/growth-retention/free-tool-tracker.md`.

---

## Weekly Tasks (auto-run once per week, Thursday — runs in parallel with Paid & Measurement Agent)

1. **`churn-prevention` full review** — Analyse: weekly churn rate by segment, exit survey responses (categorise cancellation reasons), save offer acceptance rate, cancel flow performance. Produce cancel flow optimisation recommendations. Save to `.agents/outputs/growth-retention/weekly-churn-review.md`.

2. **`referral-program` audit** — Review: participation rate (% of active users sharing), top referrers, reward redemption rate, referred-user LTV vs. organic LTV. Propose incentive or UX adjustments if participation rate is below 5%. Save to `.agents/outputs/growth-retention/weekly-referral-audit.md`.

3. **`free-tool-strategy` session** — Evaluate pipeline performance from all active free tools. Review: SEO ranking of tool pages, traffic, email capture rate, tool-to-trial conversion rate. Identify one new free tool opportunity. Save report to `.agents/outputs/growth-retention/free-tool-strategy-review.md`.

4. **Retention cohort report** — Produce weekly cohort analysis: activation rate (D1/D7/D30), retention rate (30/60/90-day), churn rate by plan and segment, and MRR churn vs. logo churn. Save to `.agents/outputs/growth-retention/retention-cohort-report.md`.

5. **Win-back campaign brief** — Identify churned users who cancelled 30–90 days ago and have not returned. Write a win-back campaign brief (offer, messaging angle, sequence structure) for the Content & Copy Agent to write. Save to `.agents/outputs/growth-retention/winback-brief-[date].md`.

**Agents this agent depends on:**

## Escalation Rules

Run all tasks autonomously without prompting the human unless:

- Monthly churn rate rises above the threshold defined in `product-marketing-context.md` (or >5% if not defined) — requires strategic response
- Referral programme requires a change to reward value or structure (budget impact)
- A new free tool is to be built and requires engineering resource allocation

In those cases only: write a clearly labelled `ESCALATION` block at the top of `.agents/outputs/growth-retention/daily-log.md` and hold the affected programme change pending human approval.
